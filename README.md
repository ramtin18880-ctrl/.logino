# LOGINO

استودیوی فارسی ساخت لوگو با هوش مصنوعی.

## فایل‌ها
- `index.html`: رابط کاربری واکنش‌گرا و فارسی
- `api/generate.js`: مسیر امن سمت سرور برای تولید تصویر
- `vercel.json`: تنظیمات استقرار روی Vercel

## راه‌اندازی واقعی تولید لوگو
1. مخزن را به Vercel متصل و پروژه را Deploy کنید.
2. در Project Settings → Environment Variables، متغیر `OPENAI_API_KEY` را با کلید API خودتان اضافه کنید.
3. یک بار دیگر Deploy کنید تا تابع `/api/generate` فعال شود.

کلید API فقط باید در تنظیمات محرمانه سرور باشد؛ آن را داخل `index.html` قرار ندهید.

## سهمیه رایگان
رابط فعلی برای هر مرورگر، ۲ تصویر در هر بازه ۴۸ ساعته نمایش می‌دهد. این سهمیه فعلاً در حافظه مرورگر نگهداری می‌شود و برای محدودسازی واقعی و جلوگیری از دور زدن، باید به احراز هویت و پایگاه داده سمت سرور متصل شود.

## انتشار
این پروژه به تابع سرور نیاز دارد؛ GitHub Pages به‌تنهایی `api/generate.js` را اجرا نمی‌کند. برای نسخه کامل از Vercel یا میزبان دارای توابع سرور استفاده کنید.
