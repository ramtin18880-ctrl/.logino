# LOGINO

استودیوی فارسی ساخت لوگو با مدل تصویرساز **FLUX.1-schnell از Black Forest Labs** از طریق Pollinations. این پروژه از OpenAI برای تولید تصویر استفاده نمی‌کند.

## فایل‌ها
- `index.html`: رابط کاربری فارسی
- `api/generate.js`: مسیر امن سمت سرور برای تولید تصویر با FLUX

## راه‌اندازی تولید لوگو
1. پروژه را روی Vercel یا میزبان سازگار با توابع serverless مستقر کنید؛ GitHub Pages به‌تنهایی فایل API را اجرا نمی‌کند.
2. در تنظیمات پروژه و بخش Environment Variables، متغیر محرمانه `POLLINATIONS_API_KEY` را بسازید.
3. مقدار آن را از حساب Pollinations خود دریافت کنید.
4. پروژه را دوباره Deploy کنید.

کلید را در `index.html` یا GitHub قرار ندهید. درخواست‌های تولید تصویر به کلید معتبر Pollinations نیاز دارند و ممکن است از اعتبار حساب مصرف کنند؛ رایگان یا نامحدود بودن تولید تضمین‌شده نیست.

## محدودیت رابط
عدد ۲ تصویر در ۴۸ ساعت فقط محدودیت نمایشی ذخیره‌شده در مرورگر است و سهمیه امن سمت سرور محسوب نمی‌شود. برای محدودیت واقعی باید احراز هویت و ذخیره‌سازی سمت سرور اضافه شود.
